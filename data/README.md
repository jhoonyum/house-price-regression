# Data

The dataset is not included in this repo.

Source: Kaggle dataset "House Price Prediction" by shree1992
https://www.kaggle.com/datasets/shree1992/housedata

To run the notebook, download `data.csv` from that page and save it in this folder (`data/data.csv` from the repo root). The notebook reads it with `pd.read_csv('../data/data.csv')`, so open and run the notebook from the `notebook/` folder.

The expected file has 4,600 rows and 18 columns: date, price, bedrooms, bathrooms, sqft_living, sqft_lot, floors, waterfront, view, condition, sqft_above, sqft_basement, yr_built, yr_renovated, street, city, statezip, country.
